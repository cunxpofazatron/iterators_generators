# Домашнее задание: Декоратор Logger

## Описание

В проекте реализован универсальный декоратор `logger`, который:

- записывает дату и время вызова функции
- записывает имя функции
- записывает аргументы вызова
- записывает возвращаемое значение
- поддерживает два режима работы:
  - `@logger` — запись в файл `main.log`
  - `@logger("file.log")` — запись в указанный файл

Также логгер применён к предыдущему проекту (итераторы/генераторы).
